# Электронная очередь поликлиники — Lab 1, вариант 6

JavaFX-приложение для работы с талонами электронной очереди.

## Требования

- JDK 21 или новее
- интернет при первом запуске Gradle Wrapper

## Запуск

```powershell
.\gradlew.bat run
```

Тесты:

```powershell
.\gradlew.bat test
```

## Реализовано

- обычные талончики и талончики на дом доступны для добавления и изменения;
- закрытые талончики доступны только для чтения и появляются из CSV;
- проверка номера карты, ФИО, кабинета, срочности, времени и адреса;
- загрузка и сохранение UTF-8 CSV;
- пропуск повреждённых строк с номером и кодом ошибки;
- корректное экранирование `;` и кавычек;
- безопасная замена сохраняемого файла через временный файл;
- JavaFX GUI с диалогами добавления, редактирования и ошибок;
- модульные тесты модели, CSV и сервисного слоя.

## CSV

```text
type;card_number;patient_name;room;urgency;taken_at;address
```

Типы: `REGULAR`, `HOME_VISIT`, `CLOSED`. Время записывается в ISO-формате, например `2026-10-12T09:30:00`. Поле `address` обязательно только для `HOME_VISIT`.

Примеры находятся в папке `samples`.
